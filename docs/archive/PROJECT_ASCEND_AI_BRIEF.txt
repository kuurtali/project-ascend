PROJECT NAME Project Ascend

MISSION Build a complete game-like Calisthenics progression platform.

IMPORTANT Do NOT create a normal workout app. Treat this as an RPG /
Skill Tree game where the player develops real physical abilities.

CORE IDEA The user starts from absolute beginner. Every movement is a
skill node. Every node unlocks another node. No advanced movement should
be available before its prerequisites.

GOALS - Build strength - Build control - Build mobility - Build
balance - Build athleticism - Reach elite calisthenics skills.

FINAL BOSSES - Handstand Push-up - One Arm Push-up - One Arm Pull-up -
Muscle-Up - Front Lever - Back Lever - Planche - Human Flag - Iron
Cross - Hefesto - Maltese - Victorian - Manna

Progression Philosophy

Never skip fundamentals.

Always prioritize: Technique Control Range of motion Consistency
Recovery

Never unlock advanced skills early.
