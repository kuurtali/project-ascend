AI DIRECTIVE

Whenever reviewing this project:

- Search for missing movement progressions.
- Search for missing regressions.
- Search for missing categories.
- Search for duplicated logic.
- Improve architecture before adding complexity.
- Never assume the movement database is complete.
- Never assume the skill tree is complete.
- Prefer scalable solutions.
- Think years ahead.

FINAL PRINCIPLE

Project Ascend should become a living knowledge base and progression engine for calisthenics.
Whenever new knowledge appears, integrate it cleanly without breaking existing systems.
