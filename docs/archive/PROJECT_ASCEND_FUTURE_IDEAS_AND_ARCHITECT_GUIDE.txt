Architecture Principles:
- Data-driven.
- Modular.
- Expandable.
- Reusable.
- Beginner to Elite support.
- Coaches supported.
- Movement database is never complete.
- Add missing movements, regressions and progressions.
- Build for years, not months.
- Prefer maintainability over shortcuts.

AI Instructions:
Read every document before making decisions.
Question existing ideas if better ones exist.
Think like a software architect, game designer, product designer, data architect and calisthenics coach.
Continuously improve architecture, UX and progression.
Design a foundation that survives years of development and can grow without breaking.
Treat the project like a bridge designed to survive earthquakes, storms and time.
Future ideas should integrate cleanly without forcing rewrites.
